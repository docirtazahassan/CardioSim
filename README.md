# CardioSim

An interactive heart simulator for medical students (USMLE level) and clinicians. It runs entirely
in the web browser – no server, no accounts, no data leaves the computer.

> **Educational tool. Not for clinical diagnosis or management.**

What it does:

- **Explore** – a 3D heart you can rotate and cut open, with the conduction system, coronary
  arteries, electrical activation in slow motion and a guided tour. The heart beats using the
  simulated circulation.
- **ECG lab** – ~40 conditions drawn on standard ECG paper (12-, 15- and 18-lead), with calipers,
  rate ruler, comparison with normal, printing, an engine-measured interpretation that explains
  *why* each finding appears, a vector lab, a lead-placement builder and axis practice.
- **Arrhythmia lab** – ~30 rhythms with a ladder diagram under the strip, PAC/PVC triggers,
  adenosine, drug and electrolyte effects on the action potential, and the resulting blood pressure.
- **Coronary lab** – click an artery to block it: territory, wall motion, bull's-eye map, the ECG
  by time since occlusion, complications and the post-infarct timeline. Dominance toggle.
- **Hemodynamics lab** – ~25 presets (heart failure, valve disease, shunts, tamponade, shock…),
  maneuvers and interventions, Wiggers diagram, pressure–volume loop, Frank–Starling and Guyton
  curves, monitor, JVP, pulse, pulmonary-artery catheter, and **auscultation** with synthesised heart
  sounds and murmurs (use headphones).
- **Equations** – 18 key formulas with sliders and graphs, linked to the simulators.
- **Cases & quiz** – clinical vignettes and ECG/rhythm drills; scores are kept in your browser.
- **Student / Clinician** switch (top right) and **Teach mode** (big fonts, answers hidden until
  clicked, keyboard shortcuts – press `?` in the app).

Everything (3D models, graphics, sounds) is generated by code; there are no downloaded images,
models, fonts or audio files.

## 1. Run it on your own computer

You need **Node.js** (version 20 or newer). Download the "LTS" installer from
<https://nodejs.org> and install it like any other program.

1. Download this project (on GitHub: green **Code** button → **Download ZIP**, then unzip it), or
   use `git clone`.
2. Open a terminal in the project folder:
   - Windows: open the folder in File Explorer, click the address bar, type `cmd`, press Enter.
   - Mac: right-click the folder in Finder → **New Terminal at Folder**.
3. Type these two commands (press Enter after each):

   ```
   npm install
   npm run dev
   ```

4. The terminal prints an address such as `http://localhost:5173/`. Open it in Chrome, Edge,
   Firefox or Safari.

To stop it, press `Ctrl + C` in the terminal.

Other useful commands:

| Command | What it does |
|---|---|
| `npm test` | Runs the 133 automatic checks of the medical behaviour (ECG patterns, hemodynamics, sounds…). |
| `npm run build` | Makes the finished website in the `dist` folder. |

## 2. Put it on the internet with GitHub Pages (free)

The project already contains the instructions GitHub needs (`.github/workflows/deploy.yml`). Every
time you change the `main` branch, GitHub tests the app and publishes it – and **refuses to publish
if any medical test fails**.

Step by step:

1. Create a free account at <https://github.com> if you don't have one.
2. Click **+** (top right) → **New repository**. Give it a name, e.g. `cardiosim`. Choose
   **Public** (GitHub Pages is free for public repositories). Do **not** add a README. Click
   **Create repository**.
3. Upload the project:
   - *Easiest:* on the new repository page click **uploading an existing file**, drag in all files
     and folders of the project **except** `node_modules` and `dist`, then **Commit changes**.
     (Make sure the hidden `.github` folder is included – on Mac press `Cmd+Shift+.` to see it.)
   - *With git:* in the project folder run
     `git remote add origin https://github.com/YOUR-NAME/cardiosim.git` then
     `git push -u origin main`.
4. In the repository go to **Settings → Pages**. Under **Build and deployment → Source** choose
   **GitHub Actions**.
5. Go to the **Actions** tab. You will see "Deploy to GitHub Pages" running (if not, click it and
   press **Run workflow**). It takes 2–4 minutes. A green tick means success.
6. Your site is at `https://YOUR-NAME.github.io/cardiosim/` (the link is also shown in
   **Settings → Pages**).

If the run shows a red cross, click it to see which step failed. "Run tests" failing means a
content change broke a medical check – see section 4.

## 3. Adding or editing content (no programming needed)

All medical content is in the folder **`src/data/`**. Each file is a list of entries written in a
simple structured format. Open the file in any text editor (VS Code is a good free one), copy an
existing entry, and change the text. Keep the commas, quotes and brackets exactly as in the
existing entries. After saving, the running app (`npm run dev`) updates immediately.

Text rules: write in your own words, explain the mechanism, give drug **classes and mechanisms
only – no doses**, and fill in the `references` field with the type of source.

### Add or edit an ECG condition – `src/data/conditions.ts`

```ts
{
  id: 'lafb',                                   // unique, lower-case, no spaces
  name: 'Left anterior fascicular block (LAFB)',
  category: 'conduction',                       // normal | axis | conduction | ischemia | hypertrophy | pericardial | electrolyte | drug | other | artefact
  level: 'student',                             // or 'clinician' (shown only in Clinician mode)
  mechanism: 'Why the ECG looks like this…',
  findings: [{ leads: 'I, aVL', finding: 'qR' }],
  criteria: ['Axis −45° to −90°'],
  mimics: ['Inferior MI'],
  pearls: ['Most common fascicular block.'],
  references: REF_ECG,
  model: { conduction: { lafb: true } },        // what the simulator should change (see below)
},
```

The `model` describes the physiology, not the drawing. Useful settings (see `EcgModel` in
`src/data/types.ts` for the full list):

| Setting | Example | Effect |
|---|---|---|
| `conduction` | `{ rbbb: true }`, `{ lbbb: true }`, `{ lafb: true }`, `{ accessoryPathway: 'left-lateral' }` | Changes the activation sequence. |
| `occlusion` | `{ artery: 'LAD', site: 'mid', stage: 'acute' }` | Coronary occlusion; stages `hyperacute`, `acute`, `evolving`, `reperfused`, `old`. |
| `regions` | `[{ segments: [7, 8], injury: 'transmural', injuryMag: 1 }]` | Injury, necrosis or T-wave change in chosen AHA segments. |
| `hypertrophy` | `{ lv: 1.9, strain: true }` | Chamber enlargement. |
| `electrolytes` | `{ k: 7.5 }` (mEq/L), `{ ca: 13 }` (mg/dL) | Changes ion currents → ECG. |
| `drugs` | `['class3', 'digoxin']` | Drug-class effects. |
| `heartRate`, `rhythm` | `110`, `'af'` | Rate and rhythm. |

Add `stages: [ { id, label, description, model } ]` to show a sequence (e.g. hyperkalemia). Run
`npm test` afterwards.

### Add or edit a rhythm – `src/data/rhythms.ts`
Copy an entry. The `model` field sets the conduction system, e.g.
`{ sinusRate: 70, av: { ahMin: 110, decrement: 300, erp: 430 } }` (Wenckebach),
`{ atrial: 'flutter', flutterBlock: 2 }`, `{ infraHis: { block: 'complete' }, escape: { ventricular: 32 } }`,
`{ ectopy: [{ type: 'pvc', pattern: 'bigeminy', couplingMs: 440 }] }`.

### Add or edit a hemodynamic preset – `src/data/presets.ts`
Copy an entry and change `params` – only what differs from a healthy adult, e.g.
`{ avArea: 0.7, lvEdB: 0.05 }` for aortic stenosis. Main parameters (units in
`src/engine/hemo/params.ts`): `lvEes` contractility, `lvEdB` stiffness, `sysR` resistance,
`totalVolume`, valve areas `avArea mvArea tvArea pvArea`, leaks `arArea mrArea trArea`, shunts
`asdArea vsdArea pdaArea`, `effusion`, `pericardialStiffness`, `hocm`, `mvp`, `hr`, `rhythm`.
Fill in `expected` (what students should see) and `pearls`.

### Add a clinical case – `src/data/cases.ts`
Copy an entry. `media` chooses what is shown: `condition` (and `stage`) for a 12-lead ECG,
`rhythm` for a strip, `preset` + `showHemo: true` for hemodynamic numbers. Each question has
`options` and `answer` (0 = first option) plus an `explanation`.

### Other content files
`structures.ts` (Explore mode cards), `coronaries.ts` (arteries, territories, post-MI timeline),
`drugs.ts`, `equations.ts`.

## 4. Medical accuracy and testing

- The ECG, rhythm, circulation and sound engines are mechanistic models; each important teaching
  point is checked by an automatic test in the `tests` folder (`npm test`).
- **`docs/CONTENT_NOTES.md`** lists every simplification, calibration constant, debated point and a
  checklist for expert review. Please read it before teaching with the app.

## 5. Technical notes (for developers)

Vite + React 18 + TypeScript, three.js via @react-three/fiber, zustand, Vitest, KaTeX. Engines in
`src/engine` are pure TypeScript (no UI), the circulation runs in a Web Worker
(`src/workers`). Architecture: `docs/PLAN.md`. Styling is plain CSS (`src/styles.css`) instead
of Tailwind, to avoid an extra build tool.
